# Sanic-Admin v0.3.1 Release Notes

> **Status: released 2026-10-23.** v0.3.1 is a patch release on top of [v0.3.0](v0.3.0-release-notes.md) fixing a user-visible defect in the admin console. No dependency or API changes.

## Fixed

- **The AMIS role form could not create or edit roles.** The "permissions" textarea submitted its raw text (e.g. `{}`), while the backend requires a dict — every create/edit answered 400 `VALIDATION_ERROR`（字段permissions必须是dict类型）, so roles could not be managed from the console. Both forms now parse the JSON before submitting (`requestAdaptor`), validate it client-side (`isJson`), and the edit dialog back-fills the stored dict as indented JSON text (`null` → `{}`). Reported from live console use; verified end-to-end in a real browser (Playwright) and against the API.

## Known limitations

Everything listed in the [v0.3.0 release notes](v0.3.0-release-notes.md) still applies, including: forced password change on first login is deferred; non-GET 405 `Allow` headers may list `HEAD` on the Sanic 25 stack; oversized bodies usually surface as a dropped connection rather than a 413; login endpoints are exempt from CSRF (login-CSRF on the backlog); `TRUSTED_PROXIES` has no environment-variable wiring yet.
