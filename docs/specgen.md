# specgen：规格即代码

规格 YAML（`specs/*.yaml`）是**唯一事实源**。确定性生成器据此产出：

| 产物 | 位置 |
|---|---|
| Tortoise 模型 | `app/generated/models/<resource>.py` |
| CRUD API（复用 `@requires_permission`、`validate_fields`、`register_view`） | `app/generated/resources/<resource>.py` |
| RBAC 权限点 | `app/generated/permissions.py`（导入时并入 `ALL_PERMISSIONS`） |
| AMIS 列表/表单页 + 菜单 | `amis/pages/<resource>-list.json`、`amis/pages/site.json`（带 `x-specgen` 标记的菜单项） |
| 契约测试 | `tests/generated/test_gen_<resource>.py` |

所有生成文件带 `generated by specgen — do not edit` 标记（JSON 用 `_generated` 键，site.json 用 `x-specgen` 菜单项标记）。**不得手改**。规格中**不得出现 AMIS 语法**（`extra=forbid`，出现即报错）；AMIS 只是 `tools/specgen/render_amis.py` 这一个可替换的渲染层。

## 命令

```bash
python -m tools.specgen validate   # 只校验规格，报「文件: 字段路径: 原因」
python -m tools.specgen generate   # 生成/更新所有产物；清理已删除规格留下的带标记陈旧文件
python -m tools.specgen check      # 只检查漂移（CI 用），有差异退出码 1
```

同一份规格两次生成逐字节相同（输出按资源名排序，无时间戳；文件头只含规格路径与内容哈希）。

## 规格格式

```yaml
resource: order            # 小写标识符；不得与内置资源 account/role/... 重名；文件名必须同名
table: orders              # 默认 = resource
plural: orders             # URL 复数，默认 resource + "s" -> /api/v1/orders
label: 订单
fields:
  - name: title
    type: string           # string | text | int | float | bool
    max_length: 128        # 仅 string，默认 255
    required: true         # 与 default 互斥
    unique: true           # 模型 unique + API 409
    format: email          # 仅 string
    choices: [a, b]        # string/int；与 default、format 的组合会被校验
    default: a             # 必须在 choices 内、类型匹配
    list: true             # 出现在 AMIS 列表
    searchable: true       # 参与 ?keyword= 搜索
belongs_to:                # 外键（RESTRICT）；API 字段名为 <name>_id
  - {name: customer, target: customer, required: true, list: true}
permissions: {actions: [read, create, update, delete]}   # 权限点 order:read ...
menu: {icon: fa-receipt, order: 70}
```

属性贯通：`default/choices/required/max_length/unique` 同时进入模型、API 校验（框架 `validate_fields`：先 `extract_whitelisted` 再校验提取结果）、AMIS 表单（select / maxLength / required / value）、生成测试。`belongs_to` 创建/更新时校验被引用记录存在（400），删除被引用的父记录返回 409。

## 自动注册（不再手工接线）

只在两个文件里各有一行**一次性**接线（已提交，之后新增资源不再改）：`app/models/__init__.py` 导入 `app.generated.models`；`app/api/resources/__init__.py` 导入 `app.generated.resources`（导入即注册路由与权限点）。菜单由生成器改写 `site.json`；测试路径替换由 `tests/conftest.py` 通用正则处理。

### 全权限角色判定

`role.py::_role_grants_all_permissions` 判定「全权限角色」时只比较**核心资源**（注册表去掉生成资源）。否则新增一份规格就会让存量全权限角色失去受保护管理员身份。内置 admin 角色仍同步为注册表全量权限（含生成资源）。

## AI 使用约定

1. **只改 `specs/`**，不手改任何生成文件；
2. 运行 `python -m tools.specgen generate`，再按改动范围跑 `tests/generated`、`tests/test_specgen.py`、`tests/test_authorization.py`；
3. 提 PR：规格改动 + 生成物在同一提交序列；CI 跑 `python -m tools.specgen check`，漂移即失败。
