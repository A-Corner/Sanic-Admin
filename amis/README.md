# amis admin 模板

基于 [amis](https://github.com/baidu/amis) 渲染器，快速搭建自己的管理系统。

## 快速开始

其实这个项目直接双击 `index.html` 都能看大部分效果，不过为了更完整体验，请运行下面的命令：

```bash

# 安装依赖
npm i
# 打开服务
npm start
```

## 部署上线

这个例子中的 amis 等依赖使用外部 cdn，为了稳定请在自己部署的时候将文件下载到本地。

## 与后端的关系（M1 起）

- `server.js` 是**本地开发用**的零依赖静态服务器：它把本目录下的页面与资源直接提供出来，
  并把 `/auth`、`/capt`、`/api`、`/health`、`/refapi`、`/account` 反向代理到后端，
  使浏览器处于同源，会话 Cookie 与登录态无需 CORS 即可工作。
- 页面里的接口基址默认同源（`window.SANIC_API_BASE` 默认为空字符串）。
  跨源部署需要自行配置 CORS 与凭据。
- 部署上线时，**后端不会**直接托管 `amis/` 目录（后端只挂载 `STATIC_DIR`，
  而仓库内并没有该目录）。请用你自己的 Web 服务器 / 反向代理在**同一域名**下提供
  `amis/` 的静态资源，并把 `/api`、`/auth` 等接口路径转发给后端，从而保持同源。

## 上传文件的下载（M1 起）

- 上传文件下载走 **`GET /api/v1/files/<id>/download`（需要登录）**。
- 后端已移除上传目录的静态挂载（否则任何人都能直接下载他人上传的文件），
  因此 **`/uploads` 路径不再提供文件**（请求返回 404）。
- 部署时请勿把 `/uploads` 写进反向代理规则或静态目录映射——那会让部署者以为
  还能从该路径拿到文件。`server.js` 也已不再代理 `/uploads`。
